## Why this package?

`@stackline/types-mdast` is the Stackline-maintained distribution of `@types/mdast@3.0.15`. It is an independent continuation of [@types/mdast](https://github.com/DefinitelyTyped/DefinitelyTyped); original authors and licenses remain credited below.

## Installation

```bash
npm install --save-dev @stackline/types-mdast
```

Preserve existing imports and plugin resolution with an npm alias:

```bash
npm install --save-dev @types/mdast@npm:@stackline/types-mdast
```

Use the original `@types/*` alias for automatic TypeScript type discovery and existing `compilerOptions.types` settings. A scoped-only installation does not automatically expose the original type-package name.
